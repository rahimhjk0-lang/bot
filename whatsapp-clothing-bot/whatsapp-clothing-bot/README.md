# بوت واتساب لبيع الجملة — قمصان وسراويل شرعية

بوت ذكي يرد على الزبائن بالدارجة الجزائرية، يقترح الموديلات مع الصور، يفاوض على السعر فحدود سمحتلو بيها، ويأكد الطلبيات (الاسم، اللقب، الولاية، الموديل، عدد السيريات) ويشعرك بيها مباشرة فواتساب. عندو لوحة تحكم ويب باش تزيد/تبدل الموديلات والأسعار والصور بلا ما تدخل للكود.

## اش فيه المشروع
- `src/whatsapp.js` — الاتصال بواتساب (مجاني، عبر مسح QR، بلا Meta Business API)
- `src/ai.js` — المحادثة الذكية (Gemini مجاني، أو Claude إذا حبيت)
- `src/catalog.js` / `src/orders.js` — تخزين السلع والطلبيات
- `src/adminServer.js` + `public/` — لوحة التحكم
- `data/` — ملفات JSON فيها السلع والطلبيات (تولد وحدها)

## 1) التشغيل على حاسوبك (تجربة قبل الرفع للسيرفر)

**المتطلبات:** Node.js نسخة 18 أو أكثر.

```bash
npm install
cp .env.example .env
```

افتح `.env` وعمر:
- `GEMINI_API_KEY` — مفتاح مجاني من https://aistudio.google.com/apikey (بحساب Google عادي)
- `ADMIN_NUMBERS` — رقمك بصيغة دولية بلا `+` (مثال: `213555123456`)
- `ADMIN_PASSWORD` — كلمة سر تختارها للوحة التحكم
- `STORE_NAME` — اسم محلك

بعدها شغل:
```bash
npm start
```

راح يطلعلك رمز QR فالطرمينال. افتح واتساب فتيليفونك (يفضل رقم مخصص للمتجر) → **الإعدادات > الأجهزة المرتبطة > ربط جهاز** → امسح الرمز. بمجرد ما يتصل، أي زبون يكتب للرقم هذا راح يرد عليه البوت.

لوحة التحكم تكون على: `http://localhost:3000`

## 2) زيادة أول موديلات
افتح لوحة التحكم، دخل كلمة السر، دوس "+ موديل جديد" وعمر:
- اسم الموديل، النوع، عدد الحبات فالسيري (عادة 12)
- السعر العادي للسيري
- **أقل سعر للتفاوض** — هذا مهم بزاف، هو الخط الأحمر لي البوت ما يقدرش ينزل تحتو مهما فاوض الزبون
- صورة الموديل (تقدر تزيد وحدة، وتزيد أكثر بالتعديل)

البوت يقرا هاذ المعلومات مباشرة، فما تحتاجش تعاود تشغل السيرفر بعد كل تعديل.

### بديل سريع: إضافة موديل من واتساب مباشرة
إذا كنت مسجل فـ `ADMIN_NUMBERS`، تقدر ترسل من رقمك للبوت:
```
#اضافة | قميص شرعي أبيض | قميص | 4800 | 4500 | 12 | من 39 لـ 46 | أبيض، كحلي
```
وأوامر أخرى: `#قائمة` (تعرض كل الموديلات ومعرفاتها)، `#خلص id` (تعلم موديل أنه خلص)، `#توفر id` (يرجعو متوفر).

## 3) الرفع لسيرفر مجاني (باش يخدم 24/24 بلا ما يبقى حاسوبك مفتوح)

الأسهل: **Render.com** (فيه خطة مجانية).

1. حط الكود فـ repository جديد على GitHub (بلا ملف `.env` — راهو مستثنى فـ `.gitignore`).
2. فـ Render: **New > Web Service** → اربط الـ repository.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. فـ **Environment**، زيد كل المتغيرات لي فـ `.env.example` (بنفس الأسماء) بالقيم الحقيقية تاعك.
6. بعد أول نشر (Deploy)، افتح تبويب **Logs** باش تشوف رمز QR ديال واتساب، وامسحو بنفس الطريقة.

⚠️ **ملاحظة مهمة على الخطة المجانية:** بعض مزودي الاستضافة المجانية يوقفو السيرفر إذا مكانش نشاط لمدة، ولمّا يرجع يخدم لازم تعاود تمسح QR (لأن الجلسة تخزن فالقرص وقد تنمسح مع كل نشر جديد فالخطة المجانية). إذا البوت أساسي فتجارتك وحاب يخدم بثبات بلا انقطاع، خطة صغيرة مدفوعة (~5$/شهر، تخزين قرص دائم) أريح بزاف من الخطة المجانية.

## 4) التكلفة الشهرية المتوقعة
- **Gemini API:** مجاني (فيه حد يومي سخي، يكفي لمئات المحادثات فاليوم).
- **الاستضافة:** مجاني (Render Free) أو ~5$/شهر (خطة مستقرة بلا انقطاع).
- **واتساب:** 0 دج — نستعملو Baileys (مكتبة مفتوحة المصدر) بلا Meta Business API ولا رسوم.

إذا حبيت تبدل لـ Claude (ردود أدق فالفهم والتفاوض المعقد)، بدل `AI_PROVIDER=claude` وعمر `ANTHROPIC_API_KEY` — التكلفة وقتها تقريباً 1-2$ لكل 1000 محادثة بموديل Haiku.

## 5) حدود النسخة الحالية (MVP) وتطويرات ممكنة لاحقاً
- تاريخ المحادثة يتخزن فالذاكرة فقط (يترجع صفر إذا عاود السيرفر يشتغل) — يكفي للاستعمال العادي، ويمكن يتطور لتخزين دائم.
- التأكد النهائي للطلبية (تأكيد الدفع والتوصيل) يبقى بيدك بعد ما توصلك رسالة الإشعار — البوت يجمعلك المعلومات ويهيألك الطلبية، وأنت تسكر الصفقة.
- تقدر تزيد لاحقاً: قاعدة بيانات حقيقية (بدل JSON)، عدة أدمين بصلاحيات مختلفة، ربط شحن/توصيل أوتوماتيكي.

## أسئلة متكررة
**واش يحتاج رقم واتساب خاص؟** الأحسن نعم، رقم مخصص للمتجر (سيم إضافي)، باش تفصل بين شخصيك وبين البوت، وباش ما يوقفش الرقم الشخصي تاعك عند أي مشكل.

**واش البوت يقدر يكذب على الزبون؟** لا، مبرمج يعتمد غير على المعلومات لي حطيتها أنت فالكتالوج (السعر، التوفر، المقاسات). إذا سولوه على حاجة ماعندوش عليها معلومة، يقول بصراحة.
